# Student Marks Analyser
A Simple python projects that calculates student marks,average,grade,and pass/fail status.
## feature
-Accepts student name
-Accepts marks for 5 Subjects
-Calculate total marks
-Calculate average marks
-Assignes grade
-Detemines pass/fail status
-saves student results
